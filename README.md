# 🛍️ **DOANFLUTTER** - SHOPEE App

Một ứng dụng thương mại điện tử hiện đại được xây dựng bằng **Flutter**, lấy cảm hứng từ Shopee. Hỗ trợ mua sắm trực tuyến mượt mà trên cả **Android, iOS & Web**.

![Flutter](https://img.shields.io/badge/Flutter-02569B?logo=flutter&logoColor=white)
![Dart](https://img.shields.io/badge/Dart-0175C2?logo=dart&logoColor=white)
![Firebase](https://img.shields.io/badge/Firebase-FFCA28?logo=firebase&logoColor=black)

---

## ✨ **Tính năng nổi bật**

- **Đăng ký / Đăng nhập** (Email & Google)
- **Khám phá sản phẩm** với tìm kiếm thông minh
- **Danh mục sản phẩm** đa dạng
- **Giỏ hàng** & **Yêu thích**
- **Thanh toán** (tích hợp Firebase)
- **Theo dõi đơn hàng** thời gian thực
- **Hồ sơ người dùng** & Quản lý địa chỉ
- **Giao diện đẹp**, mượt mà, hỗ trợ Dark Mode
- **Tối ưu hiệu năng** & Responsive Design

---

## 🛠️ **Công nghệ sử dụng**

- **Framework**: Flutter (Dart)
- **Backend**: Firebase (Authentication, Firestore, Storage)
- **State Management**: Provider / Riverpod / Bloc (tùy theo bạn đang dùng)
- **UI/UX**: Material 3 + Custom Design
- **Architecture**: Clean Architecture / MVVM
